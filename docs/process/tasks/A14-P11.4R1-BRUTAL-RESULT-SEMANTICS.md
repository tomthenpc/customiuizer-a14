# A14-P11.4R1 Brutal result semantics

TaskId: `A14-P11.4R1`
RiskTier: `R3`
State: `IN_PROGRESS`

## Goal

Fix the Brutal mutation suite so that it reports truthful, fail-closed result
semantics.  The previous implementation mixed `MUTATION_APPLIED`,
`SELF_DETECTION_ONLY`, `CANNOT_VERIFY` and `GATE_ERROR` into a single
`KILLED` counter, which allowed the suite to claim 66/66 mutations were
independently killed when only 11 had real independent gates.

This phase (R1) does **not** create 55 new independent product gates for the
source-level mutations.  It only fixes the runner, scanner, configuration and
CI so that the system:

- distinguishes apply checks from kill gates;
- no longer counts self-detection as a semantic kill;
- does not claim "all mutations killed" unless every required independent
  mutation is actually killed by an independent gate;
- protects against shell injection in command templates;
- runs a fast subset on pull_request/push.

## Changes

- `tools/brutal_gate_protocol.py` (new)
  - Exit-code protocols for apply checks and independent kill gates.
  - `validate_id`, `validate_command_template`, `render_command`, `run_command`.
  - `classify_apply` and `classify_kill` functions.

- `tools/brutal_test_runner.py`
  - Removed `shell=True` for all gate commands; commands are now argv lists.
  - Replaced `KILLED`/`SURVIVED` binary with eight explicit statuses:
    `MUTATION_NOT_APPLIED`, `MUTATION_APPLIED`, `INDEPENDENT_GATE_KILLED`,
    `SELF_DETECTION_ONLY`, `SURVIVED`, `CANNOT_VERIFY`, `GATE_ERROR`,
    `CLEANUP_ERROR`.
  - Summary now reports independent kill rate, not an inflated all-killed rate.
  - Enforces `minimum_independent_kills` and `required_independent_mutations`.

- `tools/brutal_a14_contract_scan.py`
  - Now an apply-check only.  Exit codes:
    - `0` = `MUTATION_APPLIED`
    - `2` = `CANNOT_VERIFY`
    - `3` = `SCANNER_ERROR`
    - `4` = `MUTATION_NOT_APPLIED`
  - Fixed `_inject_hazard` AST extraction to support `_inject_hazard(root, body)`.

- `tools/brutal_test_config.json` (schema_version 2)
  - `coverage_target`: 74.
  - `minimum_independent_kills`: 11.
  - `required_independent_mutations`: the 11 mutations with existing
    independent gates.
  - `apply_checks` / `kill_gates` command tables.
  - Per-mutation `apply_check`, `kill_gate`, `required_independent`,
    `coverage_status`.

- `tools/tests/test_brutal_gate_protocol.py` (new)
  - Protocol constants, id validation, command rendering, classification and
    safe `run_command` tests.

- `tools/tests/test_brutal_a14_contract_scan.py` (new)
  - Temporary git repo tests for:
    - normal mutation returns `MUTATION_APPLIED` (0);
    - pattern-count-preserving mutation returns `MUTATION_NOT_APPLIED` (4);
    - mutator with no extractable pattern returns `CANNOT_VERIFY` (2);
    - `_inject_hazard(root, body)` two-argument form is supported.

- `.github/workflows/a14-fast-ci.yml`
  - Added `Brutal suite fast subset` step: `hermeticity` + `determinism`.
