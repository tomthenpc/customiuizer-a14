- Logic guarded by `Build.VERSION.SDK_INT` on A14 is `>=` lower APIs; no `< 34` dead branches were found.

## Notes on risky but retained features

1. **Dynamic subKey preferences** (`system_statusbar_batterytempandcurrent_*`, `showdevicetemperature_*`, `mobile_digital_signal_*`) are read via `system_statusbar_${subKey}_*` in `SystemUIStatusBarHooks.kt` / `DeviceInfoMonitor.kt`. Kept as `KEEP_GUARDED` / `WAITING_FOR_SAMPLE`.
2. **Runtime action keys** (`*_action` derived from list-preference bases) are written by the action picker and consumed by `GlobalActions`, `LauncherGestureHooks`, `NavBarActionsFeature`, etc. Kept as `KEEP_GUARDED`.
3. **API102-only code** (`Api102HookBridge`, `XposedApiCapabilities` replace-hook checks) is intentionally isolated and not wired. Classified `EXPERIMENTAL` and retained per project rule.
4. **Hidden/commented preferences** that have no code are documented in `A14_DEAD_CODE_CANDIDATES.md` as `DELETE_DEAD`; they are not counted as feature rows above.
