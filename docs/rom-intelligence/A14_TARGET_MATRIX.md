This matrix maps CustoMIUIzer A14 features and core hook contracts to their
HyperOS 1 / Android 14 (A14) target classes, methods, and fields.
The upstream HyperOS 2 / Android 15 (A15) target column is left as
`WAITING_FOR_SAMPLE` because no A15 ROM samples are available yet.

Columns:

* `Feature ID` — CustoMIUIzer feature identifier or a synthetic contract id.
* `HyperOS1/A14 target` — the smali-style A14 target signature.
* `upstream HyperOS2/A15 target` — A15 target signature (waiting for sample).
* `class/method/field` — the kind of member being targeted.
* `declared class` — the class that declares the target.
* `target process` — the Android/HyperOS process where the class lives.
* `ClassLoader` — the loader used to resolve the target process.
* `DexKit signature` — the DexKit search signature or `WAITING_FOR_SAMPLE`.
* `change type` — expected change category for A15.
* `current verification status` — how the A14 target was derived.
