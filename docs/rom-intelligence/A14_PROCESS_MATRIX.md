## Notes

- `Status` = `STATIC_VERIFIED` means the row was reconstructed from source files; it does not imply device-level hook or behavior verification.
- `app set: <pref_key>` in `Allowed Processes` means the feature is gated by `PrefMap.getStringSet("<pref_key>")` and only runs in the packages contained in that set.
- `Target Packages` is the package or package group the installer is invoked for; actual per-feature process is refined by `evaluateEnabled` and `FeatureInstallRegistry`.
- `Hook Evidence` shows the mod/hook function and first-level `findAndHookMethod` / `hookAllMethods` / `findClassIfExists` sites extracted from the corresponding `mods/*.kt` file.
- `Failure Strategy`: every feature is wrapped by `FeatureInstallRegistry.installOne`, which catches `Throwable` and records `FAILED_TRANSIENT`; `OutOfMemoryError` is rethrown at the boundary.
